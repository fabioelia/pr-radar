PR Radar settings

What the side panel tracks, and the GitHub token it reads with.

GitHub token

Stored only in this browser profile. Use a fine-grained token (steps below) or a classic token with the repo scope.

How to set up a fine-grained token
  1. Open GitHub → Fine-grained tokens → Generate new token. Name it PR Radar and pick an expiration. You'll paste a new one here when it expires.
  2. Resource owner: the organization that owns the repos you track. A fine-grained token covers one owner, and the panel uses one token, so for repos under several owners use a classic token instead.
  3. Repository access: All repositories, or Only select repositories with the ones you track.
  4. Permissions → Repositories → Add permissions:
    PermissionAccessUsed for
    Pull requestsRead and writePRs, reviews; Mark ready, Convert to draft, Close
    IssuesRead and writeComments (QA and Playwright reports, session links); adding and removing labels
    ContentsRead-onlyA PR's commits, which is how its checks are found
    Commit statusesRead-onlyStatus checks
    ActionsRead and writeCheck results, job logs and screenshots; Re-run
    MetadataRead-onlyAdded by GitHub automatically
    Only reading, no buttons? Make all of them Read-only.
  5. Generate token, copy it, paste it below, and click Test token. If the organization requires approval, its repos don't show up until an owner approves the token.
  6. Check access on one of your repos: every row should be green, and Check runs gray. GitHub doesn't give fine-grained tokens check runs, so the panel reads the same results from the Actions API.

A classic token is simpler: create one with the repo scope, and authorize it for the organization's single sign-on (Configure SSO) if the organization uses it.

    Notifications

    PR Radar notifies when something you chose changes: a check marked Notify when it finishes, a label marked Notify when added, a report marked Notify on change, a new PR in your list, and anything on a PR you watch with its bell.

    No test notification? On a Mac, open System Settings → Notifications, find Google Chrome, and allow notifications with the Banners or Alerts style. Also check that a Focus mode isn't on. (The menu bar app draws its own cards in the top-right corner unless it is signed with an Apple developer certificate.)
